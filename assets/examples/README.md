# Recorded workflow examples

`sing.mp3` is the original 208.3-second Mureka 9.5 output from the site owner's
2026-11-13 Nanoodle demo run, preserved at their request for the public song
player. The brief asked for a song about the singularity. It is served as a
static example on both MCP sites; listening never calls a model or creates a
payment quote. The audio has not been transcoded.

The action-clip and 3D turntable examples come from the published Nanoodle
gallery at `nanoodlecom/nanoodle`, commit
`1b8ed79548d4d98a9a5ee5ff4f3edf85b905f46e`. The action clip was remuxed for
progressive playback without changing its video or audio streams.
