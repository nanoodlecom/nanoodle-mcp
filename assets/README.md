# Browser and brand assets

`near-site.js` is the NEAR landing page and browser workflow studio, built from
`src/near-site-browser.mjs`. `near-wallet.js` is the NEAR/USDC wallet payment
page, built from `src/near-pay-browser.mjs`. Rebuild both with
`npm ci && npm run build:near-wallet`.
The payment bundle includes NEAR Connect 0.12.0
(MIT, HOT Labs), pinned as a build dependency.
The Node server keeps its existing two runtime dependencies. Wallet discovery
and wallet executors come from NEAR Connect's upstream manifest; the payer's
private keys stay in their wallet. Attribution is in `near-wallet.LICENSE.txt`.

Served by `--serve` at `/favicon.ico`, `/favicon.png`, `/apple-touch-icon.png`,
`/icon-512.png`, and `/og.jpg` (the landing page's social card), plus
`/righteous-latin.woff2` and `/righteous-latin-ext.woff2` — the Righteous
display font (Google Fonts, OFL) self-hosted for the landing page's wordmark
and headings, the same font nanoodle.com ships for its own logo.

Both source images were generated by nanoodle workflows — the same kind of graph
this server hosts:

- **Icon** (`icon-512.png` and the favicons cut from it): the
  [favicon](https://github.com/nanoodlecom/awesome-noodles/blob/main/graphs/favicon.noodle-graph.json)
  noodle — brand description in, one bold square glyph out.
- **OG card** (`og.jpg`, 1200×630): rendered from the landing page's own brand
  (dot grid, gradient Righteous wordmark, port-colour dots) so the share card
  matches the page it links to. Earlier versions came from an og-card noodle.

To regenerate, run the favicon graph with your own brand text and resize the
result (e.g. `magick icon.jpg -resize 48x48 favicon.png`,
`magick icon.jpg -define icon:auto-resize=48,32,16 favicon.ico`).

The original **255labs Brand System v1.1.0** kit from
[branding.255labs.xyz](https://branding.255labs.xyz/downloads/) is pinned under
`brand/255labs-v1.1.0/`, including its manifest, original SVG lockups, Manrope and
IBM Plex Mono WOFF2 fonts, CSS tokens and font licenses. All 37 file digests in
the supplied manifest were verified. The NEAR site keeps Nanoodle’s Righteous
identity, dark dot canvas and model-port colors while using the brand kit’s
body type, labels, focus color and original 255labs endorsement. Essential
controls are at least 44px high. The primary MCP page presents Nano; the NEAR
page presents NEAR and enabled USDC.
